# StreamPump 质感升级方案（体检报告 §6 第 4 步）

> 日期：2026-06-22 ｜ 前置：批 1–3 + (5)(6) 已完成（token 单源、elevation 收敛、字阶、状态色解耦、IA 清理）。
> 目标：在不改品牌色与信息架构的前提下，把"玻璃/液态"质感提一个档次——更克制、更一致、更高级，去掉偏塑料感的强反光与过载的氛围动效。
> 原则：**全部参数化 + 分小步 + 每步可独立回退（git）**。每步都可单独审查。

---

## 0. 现状诊断（基于 globals.css 实测参数）

| 质感元素 | 当前实现 | 问题 |
| --- | --- | --- |
| 湿玻璃边缘反光 `::after` | shell `inset … rgba(255,255,255,0.82)`、card `…0.9`、toolbar `…0.7`，opacity .72 | 白光过强、偏"塑料/水渍"，且每个类参数各不相同（0.7/0.82/0.9），不一致 |
| 顶部高光 `::before` | shell/card 各写一条 `linear-gradient(155deg, rgba(255,255,255,0.14)…)` | 强度尚可但未参数化、重复实现 |
| 亮玻璃 vs 暗玻璃 | `.glass-card` 用白 0.10→0.04（奶白），`liquid-card`/surface-2 用蓝黑 | 两种质感混用，同页卡片观感不统一 |
| 氛围 orb | 5 个 `backdrop-orb`，blur 120px，opacity 0.5，22–32s | 数量多、整体偏亮偏躁，分散注意力 |
| 主按钮发光 | `0 18px 34px rgba(222,64,42,0.28)`，hover `…0.34` | 红色辉光偏强，略喧宾夺主 |
| 卡片 hover 抬升 | `translateY(-2px)` + 重阴影 | 幅度略大，密集列表里跳动明显 |

## 1. 升级方案（4 个小批，按风险从低到高）

### 批 4a · 氛围背景克制（风险最低，纯背景，秒回退）

- orb 数量 **5 → 3**（保留 1、3、5，移除 2、4 或在 JSX 里少渲染两个）。
- orb 透明度 `opacity: 0.5 → 0.32`；blur 保持 120px；动画时长略放慢（+4s）求更稳。
- `.explore-mesh-bg` 三层径向渐变透明度各下调约 30%。
- **预期**：背景更安静、内容更聚焦，玻璃层次更清晰。
- **风险**：几乎为 0；纯装饰层。**回退**：单文件 git revert。

### 批 4b · 统一并收敛高光/反光（核心观感升级，中风险）

新增参数 token，把分散的 `::before/::after` 参数收成一处：

```
--sheen-top: rgba(255,255,255,0.10);   /* 顶部高光强度，原 0.14 略降 */
--edge-light: rgba(255,255,255,0.55);  /* 边缘反光强度，原 0.82–0.9 大幅降 */
--edge-opacity: 0.55;                   /* 原 0.72 */
```

- `.liquid-glass-shell::after`、`.glass-card::after`、`.glass-toolbar::after`、`.liquid-pill` 的白光 inset 全部改引 `--edge-light`/`--edge-opacity`，**参数统一**且强度下调（0.82–0.9 → 0.55）。
- `::before` 顶部高光改引 `--sheen-top`（0.14 → 0.10）。
- **预期**：去掉"水渍/塑料"感，变成更细腻的哑光玻璃；所有玻璃面反光一致。这是"提一个档次"最直接的一步。
- **风险**：中——改的是品牌签名观感。**回退**：token 改回原值即恢复，单点可调。
- **可调尺度**：反光强度是一个连续旋钮（0.40 更哑光 / 0.55 适中 / 0.70 接近现状）——见文末提问。

### 批 4c · 玻璃质感归一：暗玻为主、亮玻仅限内容卡（中风险，触点较多）

- 定位 `.glass-card`（19 处）：区分"内容/媒体卡"（PostCard 等，保留亮玻璃，但奶白从 0.10→0.04 收到 **0.07→0.03**，减奶感）与"功能卡"（迁到 `surface-2` 暗玻璃）。
- **预期**：同页卡片质感统一，信息卡沉稳、内容卡仍有通透感。
- **风险**：中——需逐处判断 glass-card 用途，触点多。**回退**：分文件回退。
- **可选**：本批可只做"glass-card 减奶白"（低风险、全局一次性），把"逐处迁 surface-2"留到后续，降低一次性触点。

### 批 4d · 发光与微交互克制（低风险）

- 主按钮 `--glow-brand`：`rgba(222,64,42,0.28/0.34) → 0.18/0.24`，阴影展开略收。
- 激活态/hover 辉光统一走 `--glow-brand` 弱档。
- 卡片 hover 抬升 `translateY(-2px) → -1px`，阴影增量略减（密集列表更稳）。
- **预期**：主行动依然突出但不刺眼，整体更高级克制。
- **风险**：低。**回退**：token/单值回退。

## 2. 建议执行顺序与节奏

4a（背景）→ 4d（发光）→ 4b（反光，核心）→ 4c（玻璃归一，触点最多放最后）。
即"先低风险立竿见影，再动签名观感，最后做触点多的归一"。每批走 `npm run build --prefix app` + 逐页 smoke，并出检查 prompt，节奏与前几批一致。

## 3. 统一的"质感旋钮"（落地后维护红利）

落地后，整套质感强度由少数 token 控制：`--sheen-top`、`--edge-light`、`--edge-opacity`、`--glow-brand`、orb 透明度。日后整体调"更哑光/更亮"只需改这几行，不再逐类 grep。

## 4. 不动的边界

不改品牌色 `#de402a`、不改 IA、不改 elevation 结构、不改字阶、不动 `prefers-reduced-motion` 与 CJK 字体栈、不把 seeded/mock 包装成 production。
